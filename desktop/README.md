# Orbit

אפליקציית שורת-תפריטים ל-macOS שמחליפה את אפליקציית השלט בטלפון. שולטת בממירי
Android TV ובטלוויזיות חכמות ישירות מהמחשב, דרך הרשת הביתית.

## מה נתמך

| סוג מכשיר | פרוטוקול | פורטים | צימוד |
| --- | --- | --- | --- |
| ממיר yes / Google TV / Android TV | Android TV Remote v2 (protobuf over TLS) | 6466, 6467 | קוד בן 6 תווים על המסך |
| טלוויזיית LG (webOS) | SSAP over WebSocket | 3000, 3001 | אישור חד-פעמי על המסך |
| טלוויזיית Samsung (Tizen 2016+) | JSON over WebSocket | 8002 | אישור חד-פעמי על המסך |

אישורי הצימוד נשמרים ב-`~/Library/Application Support/tv-remote/devices.json`
(הרשאות `600`) ומשמשים בכל חיבור עתידי — מצמדים פעם אחת בלבד.

## הפעלה

```sh
npm install
npm start          # הרצה מהמקור
npm run dist       # אריזה ל-DMG (Apple Silicon)
```

בהפעלה הראשונה החלון נפתח בהגדרות. לוחצים **חפש מכשירים**, מוסיפים את מה שנמצא,
ומבצעים צימוד. אחר כך האייקון בשורת התפריטים פותח את השלט, וגם `⌘⇧T`.

כל ההסברים — צימוד, סטים, אפליקציות, CEC והדלקה מרחוק — נמצאים גם בתוך
האפליקציה עצמה: הגדרות ← **?**. הקבצים כאן הם עותק, לא המקור.

אם טלוויזיה הייתה כבויה בזמן החיפוש היא לא תשדר את עצמה — מדליקים אותה ומסמנים
**סריקה עמוקה**, שסורקת כל כתובת ברשת המקומית.

## סטים — שלט אחד לכל החדר

סט מחבר מסך וממיר ליעד אחד, וכל פקודה מנותבת למכשיר שאמור לטפל בה:

| פקודה | יעד |
| --- | --- |
| ניווט, OK, חזרה, מדיה, טקסט, ערוצים | הממיר |
| עוצמת שמע, השתקה | המסך |
| כיבוי מסך, בחירת מקור | המסך |
| הפעלה / כיבוי | שניהם יחד |

הניתוב אינו נוקשה: אם המכשיר המועדף חסר, מנותק, או לא מצהיר על תמיכה בפקודה,
היא נשלחת לשני. זה מה שגורם לעוצמת השמע לעבוד גם מול טלוויזיה בלי שליטה
ברשת — הממיר מעביר את מקשי העוצמה ב-HDMI-CEC.

סטים נוצרים בהגדרות. מכשיר שלא שויך לסט נשאר זמין בפני עצמו בבורר.

## אפליקציות

הרשימה נבנית אחרת בכל פלטפורמה, כי היכולות שונות:

- **LG ו-Samsung** מדווחות על האפליקציות המותקנות, אז הרשימה חיה ואמיתית.
- **Android TV** לא יכול: הפרוטוקול מכיל הודעה אחת בלבד לאפליקציות —
  `RemoteAppLinkLaunchRequest{ app_link }` — ואין בו בקשה למנות אפליקציות.

לכן הממיר מתחיל מקטלוג של קישורים מוכרים, ו**לומד**: הפרוטוקול כן משדר את
האפליקציה שרצה כרגע (`current_app`), אז כל אפליקציה שתפתח עם השלט הרגיל תופיע
ב"ניהול אפליקציות" כהצעה לשמירה בלחיצה. אפשר גם להוסיף ידנית קישור עומק או שם
חבילה.

## מקשי מקלדת

| מקש | פעולה |
| --- | --- |
| חיצים | ניווט |
| `Enter` | אישור |
| `Backspace` | חזרה |
| `רווח` | נגן / השהה |
| `H` | מסך הבית |
| `M` | השתקה |
| `+` / `−` | עוצמת שמע |
| `PageUp` / `PageDown` | ערוץ |
| `Esc` | סגירת החלון |

שדה הטקסט שולח מחרוזת שלמה לטלוויזיה בבת אחת — נוח לחיפוש בלי לנווט על מקלדת
המסך תו-תו.

## הדלקה וכיבוי

כיבוי עובר בערוץ הרגיל. **הדלקה** של מכשיר כבוי לא יכולה לעבור בו, כי שקע
הבקרה מת יחד איתו — לכן נשלחת חבילת Wake-on-LAN. זה דורש שהמכשיר יישאר מחובר
לרשת בכיבוי:

- **LG** — `הגדרות ← כללי ← מכשירים ← הגדרות טלוויזיה נוספות ← הפעלה דרך Wi-Fi`
- **Samsung** — `הגדרות ← כללי ← מנהל רשת ← הפעלה עם מכשיר נייד`

כתובת ה-MAC של LG נלמדת אוטומטית בצימוד; של סמסונג נקראת מנקודת המידע שלה.

## טלוויזיה בלי חיבור רשת

טלוויזיה ישנה שאין לה שליטה ברשת עדיין נשלטת דרך הממיר המחובר אליה ב-HDMI:
הכפתורים **⏻ טלוויזיה** ו-**מקור** שולחים `KEYCODE_TV_POWER` ו-`KEYCODE_TV_INPUT`,
שהממיר מעביר לטלוויזיה ב-HDMI-CEC. דורש ש-CEC יהיה מופעל בטלוויזיה — יצרנים
קוראים לזה בשמות שונים (LG: *SIMPLINK*, Samsung: *Anynet+*).

## מבנה

```
src/main/
  index.js          תהליך Electron: tray, חלון, קיצור גלובלי, IPC
  hub.js            רישום מכשירים, ניתוב פקודות בסט, ניהול אפליקציות
  store.js          שמירה אטומית של מכשירים, סטים ואישורי צימוד
  apps.js           קטלוג קישורי עומק וזיהוי חבילות שנלמדו
  discovery.js      גילוי mDNS + סריקת פורטים ברשת
  wol.js            Wake-on-LAN
  drivers/
    androidtv.js    Android TV Remote v2
    webos.js        LG SSAP
    tizen.js        Samsung Tizen
src/renderer/       ממשק המשתמש (HTML/CSS/JS, ללא framework)
```

כל דרייבר חושף את אותו ממשק — `connect`, `send(cmd, arg)`, `wake`, `capabilities`
ואירוע `status` — כך שה-UI לא יודע באיזה פרוטוקול מדובר. כפתור שהדרייבר הנוכחי
לא תומך בו פשוט נעלם.

## פיתוח

```sh
TV_REMOTE_DEV=1 npm start     # פותח את החלון מיד + DevTools + לוג שגיאות
npm run discover              # בדיקת גילוי מכשירים משורת הפקודה
npm run smoke 192.168.1.42    # בדיקת פרוטוקול ישירה מול ממיר
```

`TV_REMOTE_SHOT=<path>` מרנדר את החלון ל-PNG ויוצא, ו-`TV_REMOTE_SHOT_JS` מריץ
JS בדף לפני הצילום — כך אפשר לצלם כל מסך בלי הרשאת הקלטת מסך.

הערה: VS Code מייצא `ELECTRON_RUN_AS_NODE=1`, שגורם לבינארי של Electron לרוץ
כ-Node רגיל בלי `app` ובלי חלון. סקריפט ה-`start` מנקה את המשתנה.

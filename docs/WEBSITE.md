# שיתוף באתר

## הקישור הקבוע

```
https://github.com/relbns/tv-remote/releases/latest/download/orbit-arm64.apk
```

הקישור הזה **לא נשבר בשחרור הבא**. GitHub מפנה אותו תמיד לגרסה האחרונה, ולכן
אין צורך לעדכן את האתר בכל פעם — מספיק לדחוף תגית חדשה.

זה עובד רק כי שמות הקבצים בשחרור אינם נושאים מספר גרסה. אל תשנה אותם.

| קובץ | גודל | למי |
| --- | --- | --- |
| `orbit-arm64.apk` | ~18MB | כל טלפון מ-2016 והלאה — ברירת המחדל |
| `orbit-universal.apk` | ~52MB | מכשיר ישן במיוחד, אם הראשון לא נתמך |

הקובץ האוניברסלי נושא שלוש ארכיטקטורות מעבד ולכן גדול פי שלושה. הפניה אליו
כברירת מחדל היא הסיבה הנפוצה להורדה שנתקעת בנייד.

## אם ההורדה נתקעת בנייד

זה קורה כמעט תמיד בגלל גודל הקובץ. סדר הבדיקה:

1. הפנה ל-`arm64` ולא ל-`universal` — שליש מהגודל.
2. ודא שהאתר מוגש ב-HTTPS. דפדפני אנדרואיד חוסמים הורדת קובץ מ-HTTP בדף מאובטח.
3. לבדיקה מקומית, הגש את הקובץ מהרשת הביתית:
   ```sh
   cd <תיקייה עם ה-APK> && python3 -m http.server 8080 --bind 0.0.0.0
   ```
   ופתח בטלפון `http://<כתובת המחשב>:8080`.

## מה לא לעשות

אל תארח את ה-APK בשירות שמעביר אותו דרך תצוגה מקדימה (Drive, Dropbox בקישור
רגיל). הם מגישים HTML במקום את הקובץ, ואנדרואיד לא יזהה אותו כחבילת התקנה.
